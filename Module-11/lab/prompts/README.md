# Prompts Directory

This directory stores assembled incident context files used as input to the LLM.

Files are generated by `scripts/build_prompt.py` and consumed by `scripts/generate_rca.py`.

## Files

- `incident_context.txt` — Generated by Lesson 02's `build_prompt.py` run
- `capstone_context.txt` — Generated during the capstone (Lesson 05)

These files are listed in `.gitignore` as they contain live incident data and may
contain sensitive information in production environments.
